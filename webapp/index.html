Исследовательский черновик, не валидированная диагностика. Результаты не предназначены для найма, медицинских решений или оценки интеллекта. Данные сохраняются в отдельной TEST-базе PostgreSQL.

Мои тесты — личный исследовательский режим

Выбери Work Values (21 вопрос) или RIASEC (60 вопросов). Оба сохраняют результаты отдельно. Русский RIASEC — экспериментальный перевод, не валидирован.

На личном телефоне введи ключ один раз: вход сохранится на 30 дней. Для постоянного входа открывай этот же адрес в Chrome, а не в новом временном окне чата.

Включено по умолчанию. На общем устройстве отключи. После входа добавь эту страницу на главный экран Chrome — другие TEST-ссылки не разделяют авторизацию.

Вход выполнен. Можно открывать профиль и проходить тесты.

Черновик содержит выбранные ответы без шифрования только в этом браузере, не в PostgreSQL. Восстановление доступно до 7 дней после последнего ответа; просроченный черновик удаляется при следующем входе. Не включай на общем устройстве. «Выйти» удаляет локальные черновики.

Посмотреть предыдущие прохождения можно без нового теста: достаточно войти в приложение.

RIASEC: O*NET Interest Profiler (USDOL/ETA), русский экспериментальный перевод, только для личного исследования. Ни O*NET, ни USDOL не одобряют UALP.
